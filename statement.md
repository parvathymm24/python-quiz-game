## PROBLEM STATEMENT
The objective of this project is to develop a command-line based quiz application using python. The application should present multiple-choice questions to the user's selected option, validate the input, and compare it with predefined correct answer.

## SCOPE OF THE PROJECT
The scope of this project is to design a program for users to engage in a quiz to test their knowledge in python . The project involves question management, user input handling, answer validation, score tracking and result generation. 

## TARGET USERS
-Students learning Python Programming 
-Beginners practicing basic programming cooncepts
-Users interested in testing their knowledge through quizzes

## HIGH- LEVEL FEATURES
1.Multiple choice Python Programming questions
2.Automated answer validation validation and feedback
3.Score and percentage calculation
4.SQLite based quiz result storage
5.Modular application architecture
6.Automated testing using Python's unittest framework
