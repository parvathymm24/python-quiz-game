# PYTHON QUIZ GAME
## OVERVIEW OF THE PROJECT
This is a modular command-line application designed to assess fundamental Python programming knowledge through multiple-choice questions. The system validates user responses, provides immediate feedback, calculates final score and stores quiz results in an SQLite database.

## FEATURES
-Predefined multiple-choice quiz questions
-Instant correct/incorrect feedback
-Automatic answer validation
-Automatic score and percentage tracking system 
-SQLite-based persistent result storage
-Automated testing using Python's unittest framework

## TECHNOLOGIES / TOOLS USED
-Python
-unittest
-SQLite
-Visual Studio Code
-Python Terminal
-Github

## INSTALLATION
1. Install Python 3.x on your system
2. Install VSCode or another Python-compatible IDE

### Clone the Repository
1.Open a terminal
2.Clone the GitHub repository using:
```bash
git clone https://github.com/parvathymm24/python-quiz-game.git
```
3.Navigate to the project directory:
```bash
cd python-quiz-game
```
## RUNNING THE PROJECT
Open the terminal in the project directory and run:
```bash
python main.py
```
## INSTRUCTIONS FOR TESTING
### Test the quiz functionality:
TEST test.py
```bash
python -m unittest test.py
```
### Test database functionality:
TEST test_task.py
```bash
python -m unittest test_task.py
```
### To execute all the availalable tests:
RUN ALL TESTS
```bash
python -m unittest discover
```
